# Implementation

Реализация структур данных с нуля на C++.

## Структура

```
implementation/
├── Vector/
├── CircularBuffer/
├── Deque/
├── ForwardList/
├── DoublyLinkedList/
├── Stack/
├── Queue/
├── Heap/
├── BinarySearchTree/
├── HashTable/
└── DisjointSets/
```

## Процесс работы

### 1. Выберите структуру

Откройте папку нужной структуры, например `implementation/Vector/`.

### 2. Ознакомьтесь с интерфейсом

Файл `Vector.h` (или соответствующий для выбранной структуры) содержит сигнатуры методов. Это описание того, что нужно реализовать.

### 3. Реализуйте методы

Заполните тело функций в файле интерфейса.

### 4. Напишите тесты

В файле `main.cpp` напишите тесты для каждого метода. Тесты проверяют корректность реализации.

## Требования к тестам

Для каждого метода следует написать один тест, который включает:
- Стандартные случаи использования (нормальные входные данные)
- Граничные случаи (пустой контейнер, один элемент, максимальные значения)

Пример:

```cpp
void test_push_back() {
    Vector<int> v;
    
    v.push_back(10);
    assert(v.size() == 1);
    
    v.push_back(20);
    assert(v.size() == 2);
    
    assert(v[0] == 10);
    assert(v[1] == 20);
    
    std::cout << "test_push_back passed" << std::endl;
}

int main() {
    test_push_back();
    return 0;
}
```

## Проверка

При компиляции код должен компилироваться без ошибок, а все тесты должны пройти успешно.
